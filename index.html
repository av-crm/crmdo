CRM — вход через Google Диск

Нужен один раз настроенный Google OAuth Client ID (см. инструкцию от Клода). Затем вставьте его сюда — он сохранится в этом браузере.

  1. console.cloud.google.com → создать проект → включить Google Drive API
  2. OAuth consent screen: External, добавить свой e-mail в Test users, scope drive.file
  3. Credentials → Create OAuth client ID → Web application → Authorized JavaScript origins: адрес, с которого открываете эту страницу (например http://localhost:8765)
  4. Скопировать Client ID и вставить ниже

Хранилище

Все данные (прайсы, история изменений, заявки) хранятся в вашем Google Диске в папке CRM_Данные, в виде JSON-файлов. Каждое сохранение создаёт новую версию — так сохраняется полная история изменений, ничего не перезаписывается.

Открыть папку CRM_Данные на Диске

Совместный доступ (для других сотрудников)

Если владелец Диска расшарил вам папку «CRM_Данные» (через «Поделиться» в Google Диске), нажмите кнопку ниже и один раз выберите эту папку — так CRM получит доступ именно к ней, не ко всему вашему Диску. Нужен только один раз на аккаунт.

Отчёт по продажам (оплаченные заявки)

Заявки в статусе «Оплачена»: номер заявки, артикул, сумма заказа, СС, логистика, стоимость размещения, ИНН.

Долг продавца (ДП)

Считается только по завершённым заявкам (статус «Завершена»): ДП = сумма поля «Размещение» всех завершённых заказов продавца − сумма оплат, введённых вручную ниже.
